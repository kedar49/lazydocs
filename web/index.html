# @lazykedar/lazydocs

## 📋 Overview

LazyDocs is a high-performance, developer-native Node CLI designed to automate documentation maintenance. By scanning code AST structures and generating documentation via Groq's high-speed LLaMA models, it ensures your project files are always accurate and readable.

## 🚀 Installation
```bash
npm install @lazykedar/lazydocs
```

## 💡 Usage

Run the generator directly targeting your source folder:
```bash
lazydocs generate --input ./src --output README.md
```
